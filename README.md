# Wadi Quṣaybah Project: Data Repository

This repository contains datasets generated by the Wadi Quṣaybah Archaeological Project.\
It serves as the central, version-controlled data archive for publications and analytical workflows associated with the project.

The repository includes both raw archival exports and structured analytical datasets.

# Dataset Categories

## A. Raw Archival Exports

The following files are direct exports from the Wadi Quṣaybah project FileMaker database:

-   `wadi_qusaybah_site_records.csv`
-   `wadi_qusaybah_transects.csv`

These files:

-   Preserve the original project database structure
-   May contain abbreviated, unlabelled, or database-specific column fields
-   Are not formatted for direct analytical use

They are provided for transparency and archival completeness.
They represent the primary field data from which structured analytical datasets were derived.

## B. Structured Analytical Datasets

The following datasets were formatted specifically for analytical reproducibility in:

**“Bayesian Optimal Allocation of Effort in Archaeological Survey: A Case Study in Wadi Quṣaybah, Jordan.” (JAS, under review–link forthcoming)**

-   `inputs_sample.csv`
-   `field_results_sample.csv`

These files are:

-   Cleaned and structured
-   Explicitly formatted for use in the Bayesian Optimal Allocation Calculator
-   Directly linked to the worked examples in the manuscript

These datasets are required to reproduce:

-   Table 1 (Initial Allocation)
-   Table 2 (Threshold-Filtered Allocation)
-   Table 3 (Updated Allocation After Posterior Updating)
-   The worked Bayesian updating example in Section 3.2

Researchers seeking to reproduce the analytical results of the manuscript should focus on these structured datasets.

# How the Data Relate to the Workflow

The analytical workflow described in the JAS manuscript proceeds as follows:

1.  Structured allocation inputs
    → `inputs_sample.csv`

2.  Field survey results
    → `field_results_sample.csv`

3.  Coverage calculation and Bayesian posterior updating
    → implemented in the allocation module

4.  Confirmed archaeological discoveries
    → documented in `wadi_qusaybah_site_records.csv`

The structured datasets support direct reproducibility of the quantitative results presented in the manuscript.

# Relationship to Code Repositories

This data repository is designed to be used alongside:

-   The Bayesian Optimal Allocation Calculator repository
-   The Sweep Width Calibration Module repository

Together, these repositories provide a complete, reproducible implementation of the framework presented in the manuscript.

# Versioning

This repository functions as the long-term data archive for the Wadi Quṣaybah Project.

Each publication that uses project data will be documented in this README under a dedicated section.\
Repository releases may be version-tagged to correspond with specific publications.

Researchers should cite the repository release associated with the publication they are reproducing.
